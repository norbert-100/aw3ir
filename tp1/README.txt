# CV en ligne - Norbert DJIGUEMDE

## 1. Présentation du projet

Ce projet consiste à créer un site web personnel présentant mon
curriculum vitae (CV) en utilisant les langages HTML5 et CSS3.

L'objectif est de présenter mon parcours académique, mes compétences,
mes expériences professionnelles et mes projets dans une interface
web moderne, claire et responsive.

## 2. Technologies utilisées

- HTML5 : structure des pages web.
- CSS3 : mise en forme et design du site.
- Visual Studio Code : éditeur de code.
- Navigateur web : affichage et test du site.
